# Feedback

Use this space for bug reports, feature requests, and suggestions for [programminglanguages.info](https://programminglanguages.info/).

To add a new programming language, create a new item on Wikidata:
[https://www.wikidata.org/wiki/Special:NewItem](https://www.wikidata.org/wiki/Special:NewItem)

To update existing language information, edit the corresponding Wikidata item. Each language page on programminglanguages.info links directly to its Wikidata entry.
